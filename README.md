# Sales Data Analysis using Python

## Project Overview
This is my first Data Science project. In this project, I analyzed sales data using Python to understand product performance, revenue, and city-wise sales.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Features
- Created and explored a sales dataset
- Checked missing values and duplicate records
- Calculated total revenue and average revenue per order
- Analyzed revenue by product and city
- Created bar charts for data visualization

## Key Results
- Total Orders: 15
- Total Units Sold: 40
- Total Revenue: Rs. 1,289,500
- Highest Revenue Product: Phone
- Highest Revenue City: Sukkur

## How to Run
1. Download the notebook from this repository.
2. Open it in Jupyter Notebook.
3. Run the cells from top to bottom.
